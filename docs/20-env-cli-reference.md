# Env + CLI Referansı

## GPU Defense / Classifier

- `--gpu-defense-mode` / `SAMURAI_GPU_DEFENSE_MODE`: `on|off`
- `--gpu-classifier-runtime` / `SAMURAI_GPU_CLASSIFIER_RUNTIME`: `tensorrt`
- `--gpu-classifier-engine-path` / `SAMURAI_GPU_CLASSIFIER_ENGINE_PATH`
- `--gpu-rdma-mode` / `SAMURAI_GPU_RDMA_MODE`: `auto|direct|host_staging`
- `--gpu-rdma-strict` / `SAMURAI_GPU_RDMA_STRICT`
- `--gpu-batch-max` / `SAMURAI_GPU_BATCH_MAX`
- `--gpu-batch-flush-timeout-ms` / `SAMURAI_GPU_BATCH_FLUSH_TIMEOUT_MS`
